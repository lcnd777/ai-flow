Barre de menus Mac

La liaison automatique nécessite l’application macOS signée et la variante Safari Mac. Seuls les quotas et leurs dates sont partagés localement. Les autres navigateurs peuvent exporter un instantané ponctuel.

Confidentialité & données

Les relevés sont enregistrés localement et peuvent être partagés avec le menu Mac si tu actives cette option : pourcentages, dates, sources et réglages. Aucun service d’analyse tiers, aucun identifiant, cookie ou jeton collecté. Le navigateur utilise normalement ta session pour charger les pages officielles, sans donner tes identifiants à AI Flow. La mise à jour automatique lit les quotas depuis les onglets Claude ou ChatGPT déjà ouverts (toutes les 2 min, et à l’ouverture de la fenêtre AI Flow), sans jamais ouvrir ni recharger d’onglet ; elle se désactive par plateforme dans « Mes comptes ». La relance programmée, désactivée par défaut, n’envoie que le message que tu as choisi, une seule fois, dans la conversation choisie. Le transfert traite uniquement le texte que tu sélectionnes ou colles volontairement, sans le conserver. La copie utilise ton presse-papiers. ChatGPT standard n’a pas de compteur automatique dans cette version ; Codex a un lecteur expérimental séparé. Les données peuvent être retardées ou devenir indisponibles après un changement d’interface. Les prévisions sont indicatives.

Version 0.7.0 bêta. Sources communes Chrome / Edge / Safari. Le ZIP Apple peut être empaqueté via Safari Web Extension Packager dans App Store Connect avec un compte Apple Developer actif, sans Mac. Xcode sur Mac reste une autre possibilité. Signature et validation sur appareils Apple restent nécessaires. Sur Safari mobile, l’arrière-plan peut être suspendu.
